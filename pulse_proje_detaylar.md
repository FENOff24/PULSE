# PULSE - Müzik Keşif Platformu

PULSE, kullanıcıların yeni müzikler keşfetmesini, şarkılar hakkında yapılan analizleri incelemesini ve topluluk trendlerini takip etmesini sağlayan web tabanlı bir platformdur. 

Bu proje, BLM2537 Ağ Tabanlı Programlamaya Giriş dersi dönem projesi kapsamında geliştirilmektedir.

## Kullanılan Teknolojiler
* HTML5
* CSS3 (Flexbox & Grid)
* JavaScript (Vanilla JS)
* Veri Saklama: Tarayıcı `localStorage` (Harici bir veritabanı kurulumu gerektirmez)

## Kurulum ve Çalıştırma Adımları

Projede herhangi bir sunucu (backend) veya harici veritabanı bulunmadığı için ekstra bir kuruluma gerek yoktur. Projeyi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

1. Bu depoyu bilgisayarınıza indirin (ZIP olarak indirin veya `git clone` komutunu kullanın).
2. İndirdiğiniz proje klasörünü **Visual Studio Code (VS Code)** ile açın.
3. VS Code eklentileri (Extensions) menüsünden **Live Server** eklentisinin kurulu olduğundan emin olun.
4. Klasör içerisindeki `index.html` dosyasına sağ tıklayın ve **"Open with Live Server"** seçeneğine tıklayın.
5. Proje, varsayılan tarayıcınızda otomatik olarak çalışmaya başlayacaktır (Örn: `http://127.0.0.1:5500/index.html`).

*Not: Uygulama içindeki ekleme, silme ve güncelleme işlemleri tarayıcının yerel hafızasında (`localStorage`) tutulmaktadır. Veritabanı yapılandırmasına ihtiyaç yoktur.*
